# GFX Tool GameLoop

**GFX Tool GameLoop** is a Windows GFX panel for GameLoop: gfx tool pubg, BGMI, Free Fire. FPS presets, HD, optimizer.

## How to use
1. Download v1.0.8.
2. Extract `GFX-Tool-GameLoop.zip`.
3. Start GameLoop.
4. Run the tool. Connect. Submit.

## FAQ

**Phone APK?**
This zip is the Windows GameLoop build. Phone gfx tool apk is a different path. Notes in `files/notes/`.

**Ban?**
Unofficial graphics panel. Use allowed emulator settings.

## Requirements
Windows 10/11. GameLoop installed.
